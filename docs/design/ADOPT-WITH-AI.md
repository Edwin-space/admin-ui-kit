# 코딩 도구로 적용하기

> Admin UI Kit의 컴포넌트 가이드와 데모를 참고해서 기존 관리자 화면 한 곳을 개선해. 먼저 현재 UI 스택, 화면 경로, 토큰, 기존 동작을 대조표로 제안한 뒤 승인받아. 승인된 부품 또는 기존 프레임워크 내 대응 부품을 재사용하고, 기존 메뉴·라우트·권한·API 및 업무 규칙을 유지해. 목업 데이터와 승인 완료 시뮬레이션은 운영 코드에 옮기지 마. 완료 후 같은 화면 폭의 전후 비교, 변경 파일과 미검증 항목, 테스트 결과를 알려줘.

작은 HTML 예제에서는 `src/tokens.css`, `src/components.css`, `src/components.js`만 사용한다. React/Vue 등에서는 기존 프레임워크의 구성으로 재사용하는 편이 적절할 수 있다. 브라우저 연결이 끊겼을 때 무슨 작업이 유지되는지는 예제가 아니라 대상 프로젝트의 실제 동작을 기준으로 한다.
