# Claude · Codex에 관리자 UI 적용 맡기기

대상 프로젝트 로컬에서 아래 문장을 사용한다. AI가 비공개 저장소를 읽지 못한다면 이 키트를 내려받아, 회사 정책이 허용하는 프로젝트 작업 공간에 필요한 파일만 복사한다. 회사 파일을 예제 저장소로 보내지 않는다.

> 관리자 UI 한 화면에 Admin UI Kit를 적용하는 작업이다. 먼저 키트의 AGENTS.md와 registry/index.json에서 필요한 부품 ID, 의존 파일, 예제 호출을 찾고, 대상 프로젝트의 실제 프런트엔드 기술과 기존 화면·컴포넌트에 대한 대응표를 작성해. 운영 동작을 바꾸지 않는 제안을 먼저 보여주고 코드 수정은 승인 후에 진행해.
>
> 승인된 화면 하나만 바꿔. 기존 프레임워크와 권한·API·업무 규칙을 유지한다. 대상 코드에서 이미 지원하는 검색·정렬·필터·페이지네이션을 잃지 않도록 해. 데이터가 없거나 확인되지 않은 기능은 만들지 마. 기본·로딩·진짜 0건·조회 오류를 구분하고 연결 상태 안내는 확인된 동작만 적어.
>
> 예제를 참고하되 데모의 상태 전환, 승인 완료 처리, 가짜 데이터를 제품에 복사하지 마. 끝나면 같은 화면 폭의 전후 캡처, 변경한 파일, 실행한 테스트, 미검증 항목을 알려줘. 다른 화면으로 확대 적용하거나 배포하지 마.
