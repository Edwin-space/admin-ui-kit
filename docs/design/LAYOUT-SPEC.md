# 관리자 UI 킷 · 대시보드 레이아웃 명세 v5

첨부 v4 시안에서 구성과 정보는 유지하고, 레이아웃마다 여백·글자 기준선·컨트롤 위치를 정리했다. **아래 시안 치수는 1070 × 766 아트보드 기준**이며 원본 영상의 픽셀을 역산한 값이 아니다. 1605 × 1149 PNG는 1.5배 내보내기 이미지다. 실제 웹의 px는 아래 구현 권장값을 사용하고, 고정 좌표로 옮기지 않는다.

## 1. 시안 배치와 구현 규칙

## 2. 크기 체계

| 역할 | 시안 크기/굵기 | 실제 웹 시작값: 글자/줄높이 |
|---|---:|---:|
| 페이지 제목 | 22/750 | 24/32 |
| KPI 숫자 | 23/750 | 28/36 |
| 패널 제목 | 13.5/700 | 16/24 |
| 승인 제목 및 일반 본문 | 10.5–11.5/450–700 | 14/20 |
| 버튼 레이블 | 11/650 | 14/20 |
| 메뉴·보조문구·배지·축 | 8.5–10.5 | 12/16 이상 |

- 시스템 한국어 글꼴 또는 프로젝트에서 쓰는 Noto Sans KR 계열을 유지한다. 텍스트 그룹의 글자 크기와 줄높이는 역할 단위로 토큰화한다. KPI 숫자·시각·퍼센트는 가능한 경우 `tabular-nums` 사용.
- 간격 기본 단위 4px. 웹 카드 간 12–16px, 카드 내부 16px, 제목→설명 4px, 헤더→본문 12px, 액션 사이 8px에서 시작. 카드 반경 12px, 요청 카드·컨트롤 8px, 메뉴 외곽 14px. 둥근 모서리를 맞추되 컨트롤, 배지, 카드가 같은 종류처럼 보이지 않게 구분.
- 웹의 밀집 데스크톱 액션은 높이 36px 이상, 터치 레이아웃은 44px 목표. 상단·승인·재시도 버튼은 동일 버튼 스타일에서 크기 변형만 사용. 버튼은 텍스트가 길어져도 잘리지 않게 하고 아이콘 단독 버튼에는 접근 가능한 이름을 부여.
- 배경/카드는 v4의 회색/흰색 계열 유지. 기본 글자 `#24282D`, 보조 글자 `#58636D`, 주요 버튼 `#252A30`, 구분선 `#E7ECEF`. 실제 상태 색상 및 포커스 테두리 대비는 브라우저에서 별도 검사.

## 3. Claude / Codex에 적용할 때

1. **PNG는 목표 외형, 이 문서는 구현 규칙**으로 사용한다. 현재 프로젝트의 인증, 권한, API, 상태 이름, 라우트는 건드리지 않는다. PNG를 화면 배경으로 넣거나 SVG 좌표를 그대로 HTML에 쓰지 않는다. 기존 컴포넌트를 먼저 재사용하고 스타일 토큰과 레이아웃부터 변경한다.
2. 데스크톱은 KPI 4열, 중단 약 2:1, 하단 3열로 시작. 예: 1024px 미만 KPI 2열 및 중단 1열, 640px 미만 KPI/하단 1열과 접히는 메뉴. 전환점은 호스트 화면의 실제 콘텐츠가 압축되거나 넘치기 직전에 조정한다.
3. 완료 체크: 같은 폭의 스크린샷으로 페이지 좌우선, 첫 줄 카드 끝선, 패널 제목/설명, 각 액션의 오른쪽 끝과 세로 중심, 타임라인 상태 열을 비교한다. 1440·1024·768·390px와 200% 확대에서 긴 한국어 제목, 큰 KPI 값, 빈 목록, 오프라인 배너가 겹치거나 잘리지 않는지 본다. 키보드 포커스와 접근 가능한 이름, 상태 색 대비도 실제 화면에서 확인한다.
4. 승인 전에 한 화면만 적용해 비교를 남긴다. 다른 프로젝트에는 승인된 토큰과 반복 패턴만 옮긴다.

검증 범위: v5 정적 시안을 렌더링해 배치와 겹침을 검토했다. 반응형, 키보드 및 실제 동작 검증은 앱에 구현한 다음의 작업이다.
