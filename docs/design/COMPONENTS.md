# 컴포넌트 가이드 v0.2

공개 카탈로그의 기본 보기인 **화면 사용 부품**은 대시보드와 별도 처리 대기열에 실제로 쓰이는 21개 항목입니다. 아래 목록의 22개는 다른 프로젝트에 두루 적용할 수 있는 **범용 부품**으로, 일부 이름은 비슷하지만 실제 화면과 모양이나 조합이 다릅니다. 화면별 미리보기·코드·상태는 [AI용 소스 목록](../../registry/index.json)의 `blocks`에서 확인합니다.


[카탈로그](../../index.html#components)에서 각 예제의 미리보기와 복사할 코드를 확인할 수 있다.

## 영상에서 가져온 13개

| 영역 | 컴포넌트 |
|---|---|
| 탐색과 맥락 | 사이드바, 페이지 헤더, 검색 입력 |
| 업무 운영 | 요약 카드, 상태 배지, 처리 대기열, 이벤트 타임라인, 예정 작업 목록 |
| 보조 지표 | 진행 막대, 미니 막대 차트 |
| 상태 피드백 | 빈 상태, 로딩 스켈레톤, 연결 상태 바 |

장면 식별자는 R01(홈 전체), R02(로딩), R03(승인·예정 작업), R04(알림 없음), R05(연결 끊김과 복구)다. 영상의 암호화폐 데이터, 브랜드, 정확한 색상과 간격은 옮기지 않았다.

## 관리자 화면 공통 확장 9개

활동 표, 버튼, 텍스트 필드, 선택 메뉴, 체크박스, 페이지 이동, 탭 내비게이션, 인라인 안내, 확인 대화상자.

## 적용 계약

- 브라우저에 `src/tokens.css`, `src/components.css`, `src/components.js`를 순서에 맞춰 연결한다. 이미 React/Vue 같은 프런트엔드가 있다면 기존 컴포넌트 위에 토큰과 규칙을 매핑하는 편이 안전할 수 있다.
- HTML/JS에서 사용하면 `.ak` 컨테이너에서 미리보기의 `AdminKit.함수({…})` 반환값을 렌더링한다. 다른 데이터에서 받은 텍스트는 키트가 이스케이프한다. 임의 HTML을 별도로 이어 붙이지 않는다.
- 버튼 동작은 `data-ak-action`의 값을 호스트 앱이 연결한다. 예: 대기열 `review:ID`, 페이지 이동 `page:N`, 취소 `cancel:DIALOG_ID`. 키트는 서버 권한이나 데이터 변경을 구현하지 않는다. 확인 대화상자를 열고 닫는 것과 서버 요청은 호스트 앱 책임이다.
- ID가 있는 입력과 대화상자는 화면 내에서 고유한 ID를 넘긴다. 빈 상태는 조회가 성공하고 0건일 때만 사용한다. 장애 중 재요청이나 쓰기 동작은 호스트가 지원하는 경우에만 표시한다.
- [작은 HTML 시작 예제](../../examples/starter.html)는 카탈로그 없이 요약과 표를 재사용하는 방법을 보여준다. `src/catalog.js`와 `src/fixtures.js`는 문서·미리보기용으로 제품에 포함하지 않는다.
