# 영상 기준 화면 예제 v0.3

[원본 참고 영상](https://www.instagram.com/reel/Df82vFABe7H/). 카탈로그의 22개 범용 컴포넌트는 그대로 유지하고, **실제 화면 예제**는 별도로 영상에 가깝게 구성했다.

| 영역 | 영상에서 관찰한 것 | 예제에서 적용한 것 |
|---|---|---|
| 외곽 | 아이콘과 짧은 라벨을 세로로 쌓은 메뉴, 선택 아이콘의 어두운 배경 | 64px 레일과 작은 제목·검색·승인 버튼. 64px은 예제가 택한 값이다. |
| 위 | 밝은 배경 위 네 개의 낮은 숫자 카드와 작은 그래프 | 검정·노랑·녹색을 소량 사용한 카드 네 장 |
| 중간 | 넓은 원형 활동 시계와 이벤트 목록, 오른쪽에 좁은 승인 카드 | 시계와 로그를 한 카드 안에 배치하고 승인 패널을 분리 |
| 하단 | 기준선 대비 위치, 실행 임박 막대, 누적 효과 시각화 세 장 | 작은 점 차트, 수평 막대, 기여도 차트; 도메인과 값은 가짜 데이터 |
| 승인 | 넓은 빈 상태, 우측 이력·예정 작업, 하단 요약 | 큰 중앙 처리 영역과 우측 이력·일정 패널 |
| 연결 | 화면 위에 작은 하단 배너, 복구 시 동기화 시각 | 하단 상태 바. 오프라인 시 예제의 승인 동작을 사용 불가로 표시 |

`src/reference-blocks.css`는 이 예제의 화면 규격이다. `src/reference-blocks.js`에 레일과 차트를 분리했다. 범용 부품을 가져가는 경우에는 기존 `tokens.css`, `components.css`, `components.js`를 사용한다. 적용 대상을 확인하기 전에는 가짜 운영 상태나 영상 업체의 기능을 재현하지 않는다. 영상 속 브랜드, 실제 콘텐츠, 편집용 줌·기울기는 사용하지 않았다.
